# IKEA or Death

A fun guessing game: **Is it an IKEA product or a black-metal band?**

## Play Online

🎮 [Play the game here!](https://jveldkam.github.io/ikea-or-death/)

## How to Play

1. Click "Start Game"
2. A name will appear on screen
3. Guess whether it's an IKEA furniture product or a black-metal band
4. Get 10 questions correct to win!

## Features

- 20 IKEA products
- 20 black-metal bands
- 10 random questions per game
- Instant feedback on your guesses
- Play again anytime

## Made with

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
